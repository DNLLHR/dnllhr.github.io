# dnllhr.github.io

Website von Daniel Lehr für die iPhone-Apps, gehostet über GitHub Pages. Jede Adresse enthält genau eine Sprache.

| Deutsch | Englisch | Inhalt |
| --- | --- | --- |
| `/` | `/en/` | Hauptseite mit allen Apps |
| `/datenschutz.html` | `/privacy.html` | Datenschutz der Website |
| `/impressum.html` | `/imprint.html` | Impressum |
| `/<app>/` | `/<app>/en/` | Info, Screenshots und Support der App |
| `/<app>/datenschutz.html` | `/<app>/privacy.html` | Datenschutzerklärung der App |
| `/<app>/impressum.html` | `/<app>/imprint.html` | Impressum für die App |

`/` und `/<app>/` folgen der Gerätesprache oder der zuletzt gewählten Sprache. Alte Links mit `#en` oder `?lang=en`
leiten auf die englische Seite weiter. Keine Cookies, keine fremden Schriften oder Skripte.
