# dnllhr.github.io

Website von Daniel Lehr für die iPhone- und iPad-Apps, gehostet über GitHub Pages.

| Adresse | Inhalt |
| --- | --- |
| `/` | Hauptseite mit allen Apps |
| `/datenschutz.html`, `/impressum.html` | Datenschutz und Impressum der Website |
| `/<app>/` | Info und Support der App (z. B. `/taproute-defense/`) |
| `/<app>/datenschutz.html` | Datenschutzerklärung der App, Abschnitte `#de` und `#en` |
| `/<app>/impressum.html` | Impressum für die App |

Sprache: `#de` oder `#en` an die Adresse hängen, sonst folgt die Seite der Browsersprache.
Keine Cookies, keine fremden Schriften oder Skripte.
